### 🚀 Sobre Mim

Sou um profissional multifuncional apaixonado por tecnologia. Minha experiência vai do **suporte técnico hospitalar** até o desenvolvimento de softwares complexos. 

- 🔭 **Atualmente trabalhando em:** Automação de **Active Directory** com Python e gestão de sistemas hospitalares.
- 🌱 **Estudando:** Aprofundamento no **Android Open Source Project (AOSP)** e customização de ROMs.
- 🎮 **Hobby:** Desenvolvimento de Mods e Scripts (GSC) para **Call of Duty: Black Ops 2 (Plutonium)**.
- 💡 **Interesse:** Criação de dashboards, sistemas de telecomunicações e infraestrutura de redes.
